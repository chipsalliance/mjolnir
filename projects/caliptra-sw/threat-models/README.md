# Summary

This folder contains a threat model for the Caliptra firmware.

It was created by digesting all Caliptra specs and RTL using Gemini 3.1 pro. The `PROMPT.md` file was used to produce the `THREAT_MODEL.md` file

The threat model is consumed during vulnerability scanning by feeding it to the model performing the analysis.

# Creating the PROMPT.md

The `PROMPT.md` file was bootstrapped in an interactive gemini session. Gemini was prompted to create a prompt for creating a threat model by an expert embedded Rust programmer.
